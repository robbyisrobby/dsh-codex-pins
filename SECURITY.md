# Security Policy

## Scope

`dsh-codex-pins` is a UI-only DeepSeek Harness plugin. It does not open
network ports, spawn processes, or read session logs. Pin ids are stored
in origin-local `localStorage`.

## Reporting a vulnerability

Please do not open a public issue for security-sensitive findings.

Email the maintainer with `[SECURITY] dsh-codex-pins` in the subject, or
use GitHub private vulnerability reporting if it is enabled on the
repository.

Redact tokens, cookies, and other secrets from any logs you share.
